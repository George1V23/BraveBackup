# Brave installation detection

Detection checks the standard Brave and Brave Origin products separately. On Windows it checks the Release (Stable), Beta and Nightly executable locations under Local AppData, Program Files and Program Files (x86), as well as the per-user registry location. Each product and channel uses its own default Local AppData user-data directory.

On Linux, detection checks `brave-browser` or `brave` for Release, `brave-browser-beta` or `brave-beta` for Beta, `brave-browser-nightly` or `brave-nightly` for Nightly, and `brave-origin` for Origin, as well as the upstream Release installation locations. It searches `/usr/bin`, `/usr/local/bin`, and `/snap/bin` before other `PATH` directories, and reports one entry per product and channel even when multiple launcher names exist. The short launcher names were verified against the installed Arch packages `brave-bin`, `brave-beta-bin`, and `brave-nightly-bin`. Launcher names are assumed to identify the product and channel; custom wrappers may violate that assumption. The data root is `$XDG_CONFIG_HOME` when absolute, otherwise `~/.config`. The detected Origin package is treated as Release: upstream defines a single Linux package name, and separate published Origin Beta and Nightly launchers have not been verified. Nonstandard launch arguments, custom user-data directories, sandboxed package layouts, and nonstandard installation locations are not detected.

These are default paths, not proof that a profile exists. Discovery reads installation metadata and does not change browser data.
